NULL CANVAS

마케팅 수신 동의

선택
시행일: 2025년 1월 1일
본 동의는 선택사항입니다.
동의하지 않으셔도 NULL CANVAS의 모든 기능을 자유롭게 이용하실 수 있습니다.
수신 내용

마케팅 정보 수신에 동의하시면 아래 내용을 받아보실 수 있습니다.

✨
새 기능 안내
업데이트된 기능과 새로운 도구를 가장 먼저 알려드립니다.
🎉
이벤트 / 프로모션
할인 혜택, 이벤트, 무료 에셋 등을 안내드립니다.
📰
뉴스레터
그래픽 디자인 팁, 창작 인사이트를 월 1회 발송합니다.
🔔
앱 푸시 알림
앱 내 중요 소식을 푸시 알림으로 전달합니다.
수신 채널
  • 이메일 (가입 시 등록한 이메일 주소)
  • 앱 내 푸시 알림
동의 철회 방법

수신 동의 후에도 언제든지 아래 방법으로 수신을 거부하실 수 있습니다.

  • 앱 내 설정 → 알림 → 마케팅 수신 해제
  • 이메일 하단 '수신거부' 링크 클릭
  • 고객센터 문의: support@nullcanvas.app
수신 거부 시에도 서비스 이용에 필수적인 안내(약관 변경, 보안 알림 등)는 계속 발송될 수 있습니다.
